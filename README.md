# ATS Resume Scanner

A smart, browser-based ATS (Applicant Tracking System) resume analyzer built for BCA / Full Stack students to check how job-ready their resume is.

### ✨ Features
- 📄 Upload PDF Resume (Drag & Drop)
- 🔍 Extracts text using PDF.js
- 📊 Calculates ATS Score out of 100
- ✅ Shows Found & Missing Keywords (Python, JS, SQL, Git, React etc.)
- 📈 Visual Score with Chart.js Doughnut Chart
- 💡 Gives suggestions to improve resume
- 💾 No backend needed - Works 100% in browser

### 🛠️ Tech Stack
- **Languages:** JavaScript, HTML5, CSS3
- **Libraries:** PDF.js (for PDF parsing), Chart.js (for visualization)
- **Concepts:** File Handling, Keyword Matching, Local Storage, Responsive UI

### 🎯 Why I Built This?
As a BCA student, I struggled to know if my resume would pass company ATS filters. So I built my own scanner that helped me improve my score from 65 to 92.
